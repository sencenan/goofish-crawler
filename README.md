# HOW TO
- go to the https://www.goofish.com/bought
- press F12 to open the devtool
- open "Goofish Data Exporter"
- refresh the page
- keep scrolling until all new items are loaded
- click on "copy"
- go to file:///Users/xianshiwu/ws/goofish-crawler by using the shortcut on the desktop
- open "items.json"
- replace the entire content by pasting
- right click the short cut
    - "New Terminal at Folder"
- copy in "node login.js" ENTER
    - make sure the you login to the Goofish
    - close the browser
    - close the terminal (terminate when asked)
- right click the short cut
    - "New Terminal at Folder"
- copy in "./run.sh" ENTER
    - make sure to use the slider when prompted
    - leave it running
